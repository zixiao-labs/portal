For design, please follow the design guidelines provided with the `@zixiao-labs/ui-kits-react` package (including the "oil ui" system). Additionally, please make full use of the `@lightning-js/lightning` package to write tests—including visual regression tests—and ensure that the logo is never placed directly as an overlay on top of images.

The @nasti-toolchain/nasti package includes built-in capabilities as well as documentation accessible via Context7.

Please ensure that the document routing has sufficient SEO (TanStack has a built-in function). The login page only needs to be visible to search engines; pages that require login to view do not need to be visible to search engines and can be handled by a client-side SPA.

GitHub OAuth login and registration are open to the public; however, only email addresses with the @zixiaolabs.com domain may be used to register employee accounts.
